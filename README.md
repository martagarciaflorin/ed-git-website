# ed-git-website

## Descripción
Repositorio de la página web corporativa para Nexo Eventos, una empresa ficticia especializada en la planificación y gestión de eventos corporativos.

## Tecnologías utilizadas
* HTML
* CSS

## Instrucciones de uso
Para visualizar la página web:
1. Clona o descarga este repositorio en tu ordenador.
2. Abre el archivo `index.html` en cualquier navegador web (Chrome, Firefox, Edge, etc.).

Website: https://martagarciaflorin.github.io/ed-git-website/
